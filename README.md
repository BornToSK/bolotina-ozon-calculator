# Юнит-экономика Ozon — Болотина

React + TypeScript + Vite. Расчёты выполняются в браузере. Редактирование SKU, соинвест, цена на витрине, массовые изменения, сценарии, оптимизатор, P&L, аналитика и Excel/JSON импорт и экспорт.

Публичная версия содержит код и тарифный снимок, без ассортимента, себестоимости и Excel-файлов магазина. На каждом устройстве загрузите свой Excel через «Загрузить Excel» или сохранённый JSON через вкладку «Настройки». Шаблон цен Ozon нужно загрузить в окно «Цены для Ozon». Данные сохраняются в localStorage данного браузера, синхронизации между устройствами нет. Для переноса используйте «Сохранить расчёт» и «Загрузить расчёт» (JSON).

## Запуск

```bash
npm ci
npm run dev
```

## Проверки

```bash
npm test
npm run lint
npm run build
```

Calculation engine: `src/calculation/`. Импорт/экспорт: `src/io/`. UI: `src/components/`. Формулы и промежуточные значения доступны при наведении на результат и в диагностике SKU. Цена на витрине = цена продавца × (1 − скидка/100) × (1 − соинвест/100). Массовое изменение соинвеста доступно для выбранных или всех SKU.

Тарифный JSON: `tariffs/ozon-2026-10-05.json`, подключение/валидация: `src/calculation/tariffs.ts`. Это версионированный снимок референса, не автоматическое обновление действующих тарифов Ozon. ASSUMPTION: недостающие параметры старого Excel восстанавливаются по общим настройкам референса; индивидуальные скрытые параметры исходной конфигурации в публичную версию не включены. Проверьте параметры после импорта. Точные результаты частных regression fixtures доступны только в локальном проекте владельца; публичный репозиторий их не содержит.

## Публикация

GitHub Pages → Source: GitHub Actions. Workflow `.github/workflows/pages.yml` выполняет тесты, lint, build и публикацию при push в main. Базовый путь автоматически берётся из имени репозитория через VITE_BASE_PATH. Секреты для публикации не нужны.
